#### 3.3.1 多版本管理（3.2 已发布）

**Prompt 多版本**：
```yaml
apiVersion: nacos.ai/v1
kind: Prompt
metadata:
  name: customer-service-prompt
  versions:
    - version: 1.0.0
      status: FORMAL
      content: |
        你是一名客服助手...
    - version: 1.1.0
      status: GRAY
      grayConfig:
        percentage: 10
      content: |
        你是一名专业的客服助手...
    - version: 2.0.0
      status: DRAFT
      content: |
        你是一名资深的客服专家...
```

**Skill 多版本**：

#### 3.3.2 审核插件（3.2 已发布）

#### 3.3.3 可见性权限（3.2 已发布）

**权限模型**：
```yaml
apiVersion: nacos.ai/v1
kind: VisibilityPolicy
metadata:
  name: skill-visibility
spec:
  resourceType: Skill
  resourceName: sentiment-analysis
  visibility:
    # 公开：所有用户可见
    - type: PUBLIC
    
    # 私有：仅创建者可见
    - type: PRIVATE
    
    # 指定用户
    - type: USERS
      users: ["user_123", "user_456"]
    
    # 指定角色
    - type: ROLES
      roles: ["developer", "admin"]
    
    # 指定组织
    - type: ORGANIZATIONS
      organizations: ["org_abc"]
```
